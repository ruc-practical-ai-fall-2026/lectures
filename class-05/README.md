# Class 05 - Data Quality and Sensor Modeling

In this class we review data quality, signal to noise ratio, and sensor modeling concepts.

## Display of Presentations

Navigate to the `presentations` folder.

```bash
cd presentations
```

Start an http-server.

```bash
bash ../scripts/start_server.sh
```
