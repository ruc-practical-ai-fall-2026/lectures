# Class 06 - ML Project Planning

In this class we study how an ML project is planned, from use case selection, through requirements formulation, model selection, scaling, formulating test requirements, staffing a team, and budgeting for the project.

## Display of Presentations

Navigate to the `presentations` folder.

```bash
cd presentations
```

Start an http-server.

```bash
bash ../scripts/start_server.sh
```
