# Class 07 - ML Project Planning II

In this class we continue study on how an ML project is planned, with emphasis on use case and model selection.

## Display of Presentations

Navigate to the `presentations` folder.

```bash
cd presentations
```

Start an http-server.

```bash
bash ../scripts/start_server.sh
```
